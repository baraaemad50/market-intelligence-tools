# Market Intelligence & Competitor Scraping Tool

An end-to-end Python web application and data pipeline designed to search Google Play Store competitors dynamically, scrape customer reviews, persist relational data into SQLite and Excel, and generate AI-powered strategic market gap reports using Google Gemini.

## Features
- Dynamic App Discovery & Multi-App Selection (Checkboxes).
- Safe and robust review scraping.
- Relational storage (`competitor_intelligence.db`) and automated Excel export (`competitor_analysis.xlsx`).
- Strategic AI Market Gap Analysis (`google-genai`).
- Interactive Cloud Dashboard powered by Streamlit.
